Before any sourced picture goes into an animation:

- Source only Public Domain, CC0 or GODL-India images, with the licence checked on the source page, at the largest
  file available. Keep a small sidecar (source URL, licence, size) with each file.
- Show the candidates as a **numbered contact sheet** plus a `SOURCES.md` table: what it is, how directly it relates
  to the line, date, licence, pixel size. Suggest a set.
- **Post the sheet in the MarkRoom** (the project's board, a tab of its own per sheet, one per group or frame) as well
  as in chat, so the user can mark picks on it. The same goes for every numbered sheet the user picks from: candidate
  looks, design stills, option sheets. If the project's board can't be reached from the account in use, start a board on
  this account, post it there and say so in one line.
  Where MarkRoom isn't installed, post the sheet in the chat instead.
- **Wait for the user's picks.** Nothing is cut out or placed until they choose.
- **Finished object cut-outs don't go to the MarkRoom** (a picked prop, coin, phone or machine): check them yourself at
  100 % and say where the file is. Post one only when the user asks for it. Character cut-outs are the exception: their
  pieces sheet goes to the MarkRoom for approval (`cutout-pieces-sheet.md`).

**Why:** the user wants to choose the pictures themselves; cutting out and placing images they then reject wastes a
round. Sheets only sent in chat can't be marked, so every sheet goes to the MarkRoom as a habit. A finished object cut-out
is not a choice, so a MarkRoom round for it is noise the user then has to clear (the user, 2026-10-29).

**How to apply:** keep candidates in a `_candidates/` folder and copy only the chosen ones to `originals/`; make
cut-outs from those with the `cutout` skill.
