When the user asks for a reference video to be studied, study only the **animation, framing and design**: camera
moves, how each object, text and photo comes in, and how things are laid out on the canvas. Don't spend effort on what
the video is about; the animation built afterwards will be on a different topic.

**Why:** the reference is there for its motion and layout, not its content.

**How to apply:** measure camera speed and easing (feature tracking), step through entrances frame by frame at 25 fps,
and note element-by-element entrance mechanics and framing rules. Write the findings to a study file in the project.

## Studying the user's own finished edit

When the user hands back their finished edit of work that was handed over (cut and finished in their editor), study it
for the changes they made, which are their corrections for the next pieces. Some of what is in it is not a change:

- **The gaps between voiceover pieces** are resets before the next animation; ignore everything in them.
- **Zooms and pans at the very start or end of a voiceover piece** are set by the user around the edit; ignore them.
- **Their finishing layers**: texture, grain, posterize (it repeats frames, which is not an export fault) and roughened
  edges. These are added in their editor; don't copy them into the build and don't read them as colour or timing changes.
- **Compare against the round that was handed over** (its own previews), never older test stills or earlier rounds, or
  changes that were never made will be reported.

Write down only the real changes (timing, sizes, what was dropped or added, how things enter) and build the next pieces
to them. Related: [[motion-rules]], [[time-to-the-voiceover]].
