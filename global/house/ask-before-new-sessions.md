name: ask-before-new-sessions
description: Keep the user's work in the chat they gave it in; never move a task to another session or sub-chat unless they say to, or ask first
metadata:
  type: feedback
---

Keep the work in the chat where the user asked for it. **Don't move a task, or part of one, into another session or
sub-chat on your own.** Do it only when the user tells you to; otherwise ask first and wait for a yes. This includes
splitting off a side task you noticed, and handing over the current task because a new message arrived.

**Why:** the user follows the work in the chat they are in. Work that moves elsewhere without asking goes out of sight,
and the result they are waiting for doesn't arrive where they expect it.

**How to apply:**
- A new message mid-task: answer it here and carry on with the task here, unless the user asks for a separate chat.
- A follow-up worth its own session: suggest it in a line and wait for the user's go-ahead before starting anything.
- Subagents that return their result to this chat (searches, checks) are fine; a separate session the user would have to
  open is not.
